# tilecut user manual

tilecut turns a large GeoTIFF into map tiles that any web map can display.

This manual covers tilecut 1.4.0. It is for GIS analysts and developers who publish raster
data on web maps, for example a satellite scene in Leaflet or OpenLayers. You need to be
comfortable with a terminal and know what a GeoTIFF is.
